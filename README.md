# Wordle Clone

A browser-based **Wordle** game clone built with HTML, CSS, and JavaScript — playable online.  
This project implements the classic Wordle experience where players guess a hidden five-letter word within six attempts and receive colored feedback for each guess. :contentReference[oaicite:1]{index=1}

---

## About

This repository contains a fully functional *Wordle*-style word guessing game created in JavaScript. The user interacts with a simple UI, inputs guesses, and receives feedback on each guess:

- **Green** indicates a correct letter in the correct position  
- **Yellow** indicates a correct letter in the wrong position  
- **Gray** indicates an incorrect letter

The game resets daily with a new target word and tracks guess feedback until the player wins or exhausts all attempts. :contentReference[oaicite:2]{index=2}

---

## Features

- Classic 6-guess Wordle gameplay  
- Keyboard input and on-screen keyboard support  
- Real-time guess validation  
- Visual feedback color coding  
- Responsive layout for desktop and mobile

## Getting Started

Follow these instructions to run the project locally.

### Prerequisites

- Modern web browser (Chrome, Firefox, Edge, etc.)

*No installation packages or backend dependencies are required.*

---

### Running Locally

1. **Clone the repository**

   ```bash
   git clone https://github.com/Rishika0331/wordle.git
   ```
2. **Open in browser**
Navigate to the project folder and open index.html
(Double-click or use your editor’s “Open in Browser” feature)

## Usage
 - Enter a valid five-letter word and press Enter.
 - Colors will indicate correct, present, or absent letters.
 - Guess up to six times to find the correct word.
